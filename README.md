# Ruize Richard Xu

Personal academic website: https://richardxd.github.io/

## Update

Edit `index.html` and the files in `assets/`, then commit and push to `main`. GitHub Pages publishes directly from the root of `main`; no build step or dependencies are required. Replace `resume.pdf` to update the CV.

## Preview locally

```sh
python3 -m http.server 8000
```

Open http://localhost:8000/.
